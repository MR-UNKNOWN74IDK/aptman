# aptman
A little gadget that converts apt commands into pacman commands :P
> Most of this project's code was generated by AI
> 100% correct conversion is not guaranteed
> Plus a bunch of rough edges


## Usage
### 1. Use directly

- Download from Releases
- Run it directly

### 2. Build manually

> If you use CLion, you can just run it directly

- Clone/download the code
- `chmod +x build.sh` (AI is so useful, you know that?)
- `./build.sh`
- Run `./build/aptman`
